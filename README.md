# Afet Hayatta Kalma Rehberi (Android)

- Rehberin kendisi: `app/src/main/assets/index.html`
- Bu dala her gönderimde GitHub Actions APK'yı derler ve **afet-rehberi-son** sürüm sayfasına koyar.
