# KAHİN X

Binance USDT vadeli işlemler için analiz, tahmin ve sanal işlem programı (Android uygulaması).

- Programın kendisi tek dosyadır: `app/src/main/assets/kahin-x.html`
- Android kabuğu (`app/src/main/java/app/kahinx`) onu arka planda çalıştırır ve bildirim gönderir.
- Her değişiklikte GitHub Actions APK'yı derler ve **Releases → KAHİN X (son sürüm)** altına koyar.

Yatırım tavsiyesi değildir.
